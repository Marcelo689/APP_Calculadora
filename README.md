# APP_Calculadora

Aplicativo de calculadora desenvolvido em Flutter para demonstrar uma interface simples, responsiva e funcional para operações matemáticas básicas.

## Objetivo

Este projeto foi criado para praticar desenvolvimento mobile com Flutter, organização de componentes e lógica de cálculo em uma interface amigável.

## Funcionalidades

- Display com leitura clara dos valores
- Teclado numérico e de operações
- Cálculo de soma, subtração, multiplicação e divisão
- Funções extras como apagar, limpar e voltar um passo
- Layout pensado para uso em mobile

## Como executar

1. Acesse a pasta do projeto:

```bash
cd meu_app
```

2. Instale as dependências:

```bash
flutter pub get
```

3. Execute o aplicativo:

```bash
flutter run
```

## Estrutura do projeto

- `meu_app/lib/` — código principal da aplicação
- `meu_app/lib/components/` — botões, teclado e display
- `meu_app/lib/models/` — lógica de memória e cálculos
- `meu_app/lib/functions/` — funções auxiliares do cálculo
- `meu_app/imgs/` — imagens do projeto para documentação

## Observação

O projeto foi pensado como exemplo didático para aprender Flutter, organização de widgets e lógica de calculadora no desenvolvimento mobile.
